# Space Glider - Учебный проект на JavaScript

## 🎯 Цель проекта
Разработка классического космического шутера с использованием чистого JavaScript, Canvas API и принципов объектно-ориентированного программирования.

## 📖 Задание
Создать игру "Space Glider" со следующими требованиями:

### Обязательный функционал:
- [x] Управление кораблем с помощью клавиатуры (← →)
- [x] Система стрельбы (Пробел)
- [x] Генерация вражеских кораблей
- [x] Система коллизий пуль с врагами
- [x] Счетчик очков и здоровья
- [x] Визуальные эффекты (взрывы, частицы)
- [x] Экран победы после первого убитого врага
- [x] Автоперезапуск игры через 5 секунд после победы

### Технические требования:
- [x] Использование HTML5 Canvas для рендеринга
- [x] Чистый JavaScript (без сторонних библиотек)
- [x] ООП подход с классами Game, Player, Enemy, Particle
- [x] Адаптивный дизайн
- [x] Кроссбраузерная совместимость
